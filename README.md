### Мои проекты

#### Проект "Система распознавания и выделения проблемных зон на снимках КТ глаза"

**Задача.**
Разработать архитектуру программного комплекса для автоматизации диагностики заболеваний глаз на основе снимков компьютерной томографии.

**Моя роль:** системный аналитик.

**Что было сделано в рамках проекта:**

*   **Сбор и анализ требований**:
    *   проведен анализ предметной области и выделены ключевые бизнес-процессы.
    *   определены роли пользователей (врач, система) и их цели.
*   **Моделирование**:
    *   построена **диаграмма вариантов использования** для описания функциональности системы.
    *   разработаны **диаграммы потоков данных**, отражающие движение информации в системе.
    *   спроектирована **диаграмма классов** и диаграмма последовательности.
*   **Документирование**^
    *   составлены детальные сценарии использования (Use Cases) с описанием основного и альтернативных потоков.
    *   написана спецификация качества ПО с определением нефункциональных требований и критериев качества.
    *   проведена трассировка требований для контроля их реализации.

**Результат:**
Спроектирована архитектура ПО, готовая к передаче в разработку. Вся проектная документация оформлена по стандартам.
